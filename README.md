# Portfolio — Bashar Mohamad

Personleg portefølje som viser fram prosjekt, kompetanse og kontaktinfo.
Live på [bashar.no](https://bashar.no).

## Teknologiar

- React + TypeScript
- Vite
- Tailwind CSS

## Utvikling

```bash
npm install
npm run dev
```

## Bygg

```bash
npm run build
```

Bygde filer hamnar i `dist/`.
